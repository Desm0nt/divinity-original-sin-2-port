# VK-NATIVE — текущее состояние (ветка `dos2-vk`, дерево `dos2-port/wt-vk`)

Задача: убрать NVN из пути рендера DOS2 целиком. Движок рисует через наш бэкенд Vulkan, поставленный на уровень его собственного
рендерера (`r = [main+0x2bbdc68]`), переключатель `DM_VK_NATIVE`. Проект и карта — `VK-NATIVE.md`, `VK-NATIVE-MAP-1…3.md`. Этот файл —
чтобы новый агент мог продолжить с места остановки.

## Открытые вопросы этапа 2 (подтвердит только телефон)
- Массивы и массивы кубов в `CreateTexture`: число слоёв берётся из записи движка.
- Упакованные 16-битные форматы (`0x95`, `0x3c`, `0x98`, `0x39`): порядок бит — догадка; транслятор их не знал, игра, вероятно, не использует.
- Глубина D24 заменяется на D32F там, где D24 нет: смещение глубины растеризации надо масштабировать (`units_x` в `vkn_state`).
- Трёхкомпонентные 8 / 16-битные атрибуты вершин без поддержки устройства читаются как четырёхкомпонентные.
- Не открыты через выход шейдеров: обрезка выходов вершинного шейдера (`DM_NR_XLQ`) и модуль без размера точки (`DM_NR_IDVS`).

3. **Исполнитель пакетов** (`vkn_exec.c`, `hle_dos2_vkn_exec.c`): свой `0x93e5f0` на 64 кода (таблица — `VK-NATIVE-MAP-3.md`); коды состояния

4. **Draw** (`vkn_draw.c`): сбросы `0x926f90 / 0x925740` в своё кольцо, набор дескрипторов из кэша по слотам, конвейер по ключу, буферы,
   `0x928e80 / 0x928fb0 / 0x9290f0`, пакет 0x23; служебный буфер и `c1`; привязка 3 с шагом 0 для отсутствующих входов.
5. **«Немедленные» draw** 0x26–0x2a (`0x92f730…0x930e90`) и переписывание индексов для веера / четырёхугольников / замкнутой линии.
6. **UI** (`vkn_ui.c`, `hle_dos2_vkn_ui.c`): 11 входов Iggy над тем же буфером команд, обновление текстур UI (пакеты 0x2c / 0x2d и
   `WriteTexels` из блока UI).
7. **«Песок» и счёт оставшихся вызовов NVN** (`hle_nvn.c`: при `DM_VK_NATIVE=1` запись команд — в локальную страницу, счёт по адресу возврата).
8. **Хост-тест этапа 3** (пакеты, записанные с телефона, против подставного Vulkan) — один на этап.
Оценка: 14–20 агент-часов работы агентов + 3–5 серий телефона (первый кадр, сравнение кадров, UI, ходьба).
Нерешённое по пакету 0x30 (применить подготовленную копию буфера посреди кадра): при своих буферах это `memcpy` — проверить на
этапе 3, что порядок с уже записанными draw не нарушается (иначе копия на GPU из блока арены).
