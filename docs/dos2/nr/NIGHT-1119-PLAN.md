# Ночь 18→19.11 — единый план (сессия-форк DOS2, ветка `dos2-night1119`)

Задача хозяина: +15–20 % fps на Mi 14 без порчи картинки, +30–35 % с «хаками»; ноль транслятора кроме шейдеров; найти, куда
«пропадают 10–15 fps после загрузки»; память и трафик; меню «Хаки» (не только разрешение, FSR на низком масштабе).
Телефона ночью не было: всё ниже собрано, покрыто хост-тестами и проверено ревьюером, но **на устройстве не запускалось**.
Все цифры выигрыша — модели, кроме помеченных «замер».

## 0. Ветка и сборка
- `dos2-night1119` (worktree `wt-night`) = `dos2-nr-all` 7780b92 + 7 ночных веток (ntrans, nmem, nrender, nhacks, ndrift, nshader,
  npreskin) + правки ревью. Слияние в `dos2-nr-all` — решение основной сессии.
- **Поведение при пустом dm/env (проверено ревьюером построчно):** меняются только
  1. `DM_DIRTY_PROTECT_ORDER=1` — исправление трёх гонок трекера грязных страниц (общее ядро всех портов; старый порядок терял запись
     20/20 в тесте на настоящем трекере). Смотреть повторы в `[vma] dirty order`; если заметно > 0 — урезать круги / убрать `sched_yield`.
  2. `DM_NR_GROWTH=1` — строка `[nr] growth` раз в 10 с (размеры кэшей / пулов, дельты с загрузки, частоты, RSS).
  3. `DM_NVN_SYNC_XWAIT=2` — только счёт `SyncWait` на нетранслированном fence.
  Проба частоты GPU (`DM_NR_GPUPROBE`) после ревью **выключена** и ограничена (рост ×8 за шаг, потолок 1<<18).
  Всё остальное — за переключателями, 0 = сегодня.
- Установщик: пак `native-nr.xgspack` принимает новые варианты (`5.` S2F, `f.` / `g.` LIGHTFUSE) как **необязательные** — сбой
  варианта у игрока не роняет пак (тест `nrpack_optional_test`). Хэш инструментов сменился → у игроков setup пересоберёт пак при
  следующем запуске; старый пак с новым APK продолжает работать.

## 1. Главный ответ: «пропажа 10–15 fps после загрузки» (NR-DRIFT)
Это не утечка и не телефон, а **DRS игры**: первые кадры после экрана загрузки стоят 26–55 мс, DRS прыгает на 75–85 % и поднимается
обратно ~20 с (1.25 %/с). Всё это время fps 105–120 на пониженном разрешении; после возврата к 100 % — настоящие 77–83 fps сцены.
45 прогонов: высота DRS после загрузки 79.9 % (75–85), fps первых 10 с 106.4, последних 10 с 81.2. При фиксированном разрешении дрейфа
нет (120.1 → 120.2 за 72 с). Кэши, RSS, тепло, ядра — без роста.
- `DM_DOS2_DRS_SETTLE=1` — держать 100 % на экране загрузки + 6 с (честная картинка сразу). Кандидат в умолчание после прогона D2.
- `DM_DOS2_DRS_SPIKE=1` — одиночный плохой кадр (вход в зону, первый эффект боя) больше не роняет разрешение на 20 с (модель ходьбы:
  7 провалов / 34 с ниже 100 % → 0 / 0). Кодовая вставка, сверка слов, Unicorn-тест 12 208 проверок.

## 2. Mi 14 без потерь качества (GPU-упор ~11.8 мс)
| Шаг | Переключатель | Модель Mi 14 | Слабые | Качество |
|---|---|---|---|---|
| Сортировка глубинных draw (NR-21) | `DM_NR_SORT=1` | **замер 19.11:** +0.7 fps стоя | больше | бит в бит |
| Небо внутри света (NR-LIGHTFUSE) | `DM_NR_LIGHTFUSE=1` | −0.4…0.6 мс | ×2–3 | бит в бит при RNE, иначе ≤ 1 ступень R11G11B10F |
| + туман в том же draw | `DM_NR_LIGHTFUSE_FOG=1` | ещё −0.15…0.25 мс | ×2–3 | то же |
| Поток «только позиция» для глубины (NR-POSONLY) | `DM_NR_POSONLY=1` | −0.25…0.5 мс (ходьба) | −0.5…1.5 | бит в бит |
| Свой GMEM/sysmem по проходу (NR-GMEM) | `DM_GFX_PASS_GMEM=1` (+`_M=1`) | −0.3…+0.5 (+0.1…0.35) | −0.7…1.1 (Adreno 6xx/7xx) | бит в бит (риск: load/store в GMEM — скриншот) |
| Склейка глубинных draw (NR-MDI) | `=2` счёт / `=3` проба | −0.15…0.5 (строить `=1`, только если M2−M1 ≥ 0.4 мс) | −0.3…1.2 | бит в бит |
| Память поисков хэша теней (NR-ZERO Z1) | `DM_NR_SHC_MEMO=1` | CPU −0.4…0.8 (fps 0) | CPU −1…2.4 | бит в бит |
**Честная сумма для Mi 14 без потерь: ≈ −1.0…2.2 мс GPU из 11.8 → +9…18 % fps** (плюс уже включённые кэш теней +2.15 fps стоя и
партия C). Верх цели хозяина (+20 %) достижим только при удачных замерах GMEM/MDI. Отвергнуто ночью с числами (не повторять):
переписи текста шейдеров на Adreno (компилятор Turnip сам снимает накладные расходы: ±20 % инструкций, ~0 мс; потолок −0.1…0.2 мс),
UBWC (на A750 уже сжато всё, кроме R8-маски теней), LRZ (замер m5/m7 12.56 vs 12.59 мс; EQUAL в G-buffer), пузыри между проходами
(A/B барьеров 63→16 = 0; снимаемо ≤ 0.03 мс), перестройка проходов в sysmem (load/store бесплатны), Z2/Z4/Z6 транслятора (~0.1 мс
каждая), предскиннинг на Adreno (весь скиннинг 0.05–0.14 мс), sync-точки CPU↔GPU (ожидания 0).
Новый инструмент: **офлайн-компилятор Adreno 750** (`tools/tu_stats`, Mesa turnip27 в WSL + поддельный kgsl) — точная статистика
шейдеров под телефон хозяина без телефона.

## 3. Хаки (страница ⚙ «Хаки скорости», `DM_HACK_*`, по умолчанию выкл.)
Состав: масштаб 3D через DRS игры + **FSR 1 EASU** (fp16, ошибка < 1 шага 8 бит; на 100 % бит в бит с FXAA-проходом), без свечения,
тени 512, лёгкий фильтр теней / Dref, без дальнего каскада, mip-bias, анизотропия, **дальности LOD** (12 мест в коде игры, 90/80/70 %),
**лимит ламп на точку** (все / 4 / 2; бит в бит, где ламп меньше).
| Уровень | Состав | Mi 14 (модель) | SD7 | G57 MC2 | Видимость |
|---|---|---|---|---|---|
| Лёгкий | 85 % + EASU, лёгкий фильтр теней, LOD 90 % | +22…34 % | +20…30 % | +25…35 % | почти незаметно |
| Средний | 85 % + EASU, LOD 80 %, 4 лампы, тени 512, mip +0.5, aniso 4 | **≈ +38 % (28…60)** | +40…60 % | +45…70 % | мягче, без «мыла» |
| Максимум | 75 %, LOD 70 %, 2 лампы, без свечения и дальнего каскада, mip +1, aniso 2 | +50…80 % (упор в CPU) | +80…110 % | +100…150 % | заметно |
Главная неопределённость — вклад LOD и ламп; если ≈ 0, «Средний» вернуть на 75 % (одна строка). Отвергнуто: SSAO (консоль его
выключила), частицы (≈ 0.3 мс), UI через кадр (0.17 мс, ломает тайлеры). Общие файлы frontend-common не менялись.

Путь «ноль транслятора» (NR-ZERO.md): остались три перегона одного draw (поток игры ≈ 4.9 мс прослойки, транслятор ≈ 6 мс, из них
3.7–4.8 ждёт GPU). Рычаг > 1 мс только у Z3 (готовый draw сразу в пакет рекордера, 8–12 ч) и Z5 (пакет прямо с потока игры, 20–40 ч,
≈ −3 мс CPU Mi 14, критический путь на слабых CPU 2 потока вместо 3). Начинать Z3 по замеру разбивок (`[nr] desc/draw by part`).

## 6. Что включать по умолчанию после прогонов (кандидаты)
- Adreno: `DM_NR_SORT=1` (уже замерен +0.7 fps), `LIGHTFUSE(+FOG)`, `POSONLY`, `GMEM` — каждый по своему ABBA; `DRS_SETTLE`, `DRS_SPIKE`.
- Все: `DM_NR_ARENA=1` (память), `DM_NR_LINTEX=1` (пики в бою), `DM_NR_SHC_MEMO=1` (CPU).
- Тайлеры: `DM_NR_COVER=1`, S2F — только после пререлиза для тестеров на Mali / PowerVR («test», CAUTION, не Latest).
- Перенос в другие порты: dirty-order (`port-common/modules/dirty-order`, migration-заметки для D16 / ETR / D3 / TL2 / XC2), фильтр
  всплесков DRS, проба частоты GPU без root, правило маски по формату, запрос сжатия у драйвера, `tu_stats` для пака Eternal.
